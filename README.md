\# 🏥 Hospital Management System



A complete desktop application for managing hospital operations – patients, doctors, appointments, prescriptions, billing, and more. Built with \*\*C# Windows Forms\*\* and \*\*SQL Server\*\*.



\## ✨ Features



\- \*\*🔐 Login with auto‑role detection\*\* – Admin, Doctor, Receptionist (no role dropdown)

\- \*\*👨‍⚕️ Patient Management\*\* – Add, edit, delete, search patients

\- \*\*👩‍⚕️ Doctor Management\*\* – Full CRUD for doctors

\- \*\*💊 Medicine Inventory\*\* – Track stock, prices, and types

\- \*\*📅 Appointment Booking\*\* – Schedule appointments, view all appointments with filters

\- \*\*📝 Write Prescription\*\* – Add diagnosis, notes, and multiple medicines

\- \*\*💰 Bill Generation\*\* – Generate bills for completed appointments, mark as paid

\- \*\*🔍 Patient Search\*\* – Search by name/phone, view full history (appointments \& prescriptions)

\- \*\*👨‍⚕️ Doctor Schedule\*\* – View appointments, mark as completed, write prescription

\- \*\*📊 Admin Dashboard\*\* – Statistics cards and quick access to all management modules



\## 🛠️ Technologies Used



\- \*\*Frontend:\*\* Windows Forms (.NET Framework 4.7.2)

\- \*\*Backend:\*\* C#

\- \*\*Database:\*\* SQL Server (local or remote)

\- \*\*Data Access:\*\* ADO.NET with stored procedures / inline queries

\- \*\*Security:\*\* Password hashing (PBKDF2 + SHA1 legacy support)
